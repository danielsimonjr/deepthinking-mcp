# Visual Grammar: 5W1H

How to render a `5w1h` thought as a diagram.

## Node Structure

5W1H scopes a problem across six dimensions radiating from a central "What" hub — a **6-spoke hub-and-spoke layout**:

- **What** (center) → A single **orange ellipse**, the anchor of the diagram. It names the central event/problem being scoped.
- **Who / When / Where / Why / How** (spokes) → **blue rectangles**, one per dimension, each pointing inward to the What hub
- Each spoke node's label is the excerpt of that field's value (join array entries with `; ` if the field is an array)

## Edge Semantics

- **Solid blue arrow** (`→`) from each spoke to the center — every dimension informs and scopes the central "What"
- No edges exist between spokes — 5W1H dimensions are independent facets of the same event, not a causal chain (that's `fivewhys`/`fishbone`'s job)

## Mermaid Template

```mermaid
graph TD
    What(("❓ What<br/>Central event"))
    Who["👤 Who"]
    When["🕐 When"]
    Where["📍 Where"]
    Why["❔ Why"]
    How["⚙️ How"]

    Who --> What
    When --> What
    Where --> What
    Why --> What
    How --> What

    style What fill:#f59e0b,stroke:#d97706,color:#000,stroke-width:3px
    style Who fill:#3b82f6,stroke:#1e40af,color:#fff
    style When fill:#3b82f6,stroke:#1e40af,color:#fff
    style Where fill:#3b82f6,stroke:#1e40af,color:#fff
    style Why fill:#3b82f6,stroke:#1e40af,color:#fff
    style How fill:#3b82f6,stroke:#1e40af,color:#fff
```

## DOT Template

```dot
digraph FiveW1H {
    rankdir=TB;
    node [shape=box, style="filled,rounded"];

    What [label="WHAT\nCentral event", shape=ellipse, fillcolor="#f59e0b", fontcolor="black", penwidth=3];
    Who [label="WHO", fillcolor="#3b82f6", fontcolor="white"];
    When [label="WHEN", fillcolor="#3b82f6", fontcolor="white"];
    Where [label="WHERE", fillcolor="#3b82f6", fontcolor="white"];
    Why [label="WHY", fillcolor="#3b82f6", fontcolor="white"];
    How [label="HOW", fillcolor="#3b82f6", fontcolor="white"];

    Who -> What;
    When -> What;
    Where -> What;
    Why -> What;
    How -> What;
}
```

## Special Cases

- **Array-valued fields**: When `who`/`what`/`when`/`where`/`why`/`how` is an array (multiple entries), join entries with `<br/>` (Mermaid) or `\n` (DOT) inside the node label rather than creating multiple spoke nodes — the diagram stays a clean 6-node hub regardless of how many facts populate each dimension.
- **`summary` field**: If present, render as a caption below the diagram (not a graph node) — it is prose, not a graph element.
- **Missing/thin dimensions**: If a dimension's value is a placeholder like "unknown" or "TBD", render its spoke with a dashed border to visually flag the scoping gap.
